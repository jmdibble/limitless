# Limitless Gym MK

One-page marketing site for Limitless Gym MK. Next.js (App Router), Tailwind v4, hosted on Vercel.

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

Business details (address, hours, phone, links) live in `src/lib/site.ts`. See `CLAUDE.md` for architecture and conventions.
